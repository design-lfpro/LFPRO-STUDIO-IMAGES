# T2 — Texture Macro

## Job

Prova **sensorial** da fórmula sem full face: pó pulverulento, creme batido, stroke de base, pigmento de sombra, bullet de batom em macro.

## Quando usar

- Soft Eye / Soft Finish (pó)
- Blend Cream / Soft Matte / Cream Color (creme)
- Batons / máscaras (textura de produto)
- Como B-roll encaixado no T1 (cena 2)

## Inputs

- Packshot + imagens de swatch do site (muitas `02`/`03` já são swatch)
- Ficha: seção textura / prompt anchors T2

## Shot list (8s)

| # | t | Tipo |
|---|---|------|
| 1 | 0–3s | Extreme macro da fórmula (swatch ou pote aberto) |
| 2 | 3–6s | Interação leve: pó caindo, stroke gloss, cream peak |
| 3 | 6–8s | Pull back sutil revelando packaging no canto (logo ok) **ou** hold macro |

## Motores (Magnific) — LOCK

| Etapa | Modelo |
|-------|--------|
| Still macro | **Nano Banana** 2k + ref swatch/packshot |
| i2v | **Seedance 1.5 Pro** (Draft/720p) |

Ver `brand-dna/01-modelos-magnific.md`.

## Motion permitido (Seedance)

- Falling powder particles (soft, not explosion)
- Cream peak soft jiggle
- Light glide across swatch
- Shallow DOF shift

## Proibido

- Aplicar na pálpebra/rosto completo (vira T5)
- Mudar cor da fórmula vs ficha
- “CGI slime” over-gloss genérico

## QC

- Cor da fórmula ≈ swatch oficial  
- Packaging se aparecer = lock  
- Sensação premium, não ASMR nojento
